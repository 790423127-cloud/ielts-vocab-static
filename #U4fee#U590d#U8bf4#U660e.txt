Edge TTS bufferUtil 报错修复说明

这个包只修复发音报错：

TypeError: bufferUtil.mask is not a function

需要覆盖 / 新增：

1. app/api/edge-tts/route.js
2. scripts/edge-tts-cli.mjs

操作步骤：

1. 先在终端按 Ctrl + C 停止网站。
2. 把本压缩包里的 app 和 scripts 文件夹复制到你的项目根目录。
3. 如果提示覆盖 app/api/edge-tts/route.js，选择覆盖。
4. 删除项目里的 .next 文件夹。
5. 重新双击 start-windows.bat，或者运行 npm run dev。
6. 打开网页后再点单词或例句发音。

说明：

这个修复不会动你的词库。
不会动 DeepSeek Key。
不会动界面。
不会动导入导出。
只是把 Edge TTS 放到单独 Node 脚本里运行，避免 Next.js 打包 node-edge-tts 时出现 bufferUtil.mask 报错。
