# 学习系统 V2：第三阶段收口说明

## 目标

第三阶段不再增加学习功能，而是固定前两阶段已经统一的页面、交互与静态版契约，删除会覆盖新标准的旧导出补丁，并把启动速度和 80%–160% 字号适配变成自动回归检查。

## 唯一来源

- Next 页面布局和字号：`app/globals.css`、共享学习组件、`app/lib/ui/font-scale.mjs`。
- 静态页面统一外壳：`public/assets/study-system.css` 与 `public/assets/study-system-runtime.js`。
- 静态首页业务运行代码：`app/lib/static-home-app-template.mjs`。
- 静态导出接口：只组装文件、写版本和校验最终 ZIP，不再按源码字符串改写 CSS 或 JavaScript 行为。
- 当前静态缓存版本：`20260810_study_system_v59`。

## 已删除的旧实现

- 导出接口内重复保存的整份静态首页 CSS。
- 导出接口内超过十万字节的静态首页 JavaScript 副本。
- ZIP 生成后依赖字符串匹配重新改写首页 CSS、筛选逻辑、字号逻辑和滑动逻辑的补丁。
- 每个静态页面单独注入的手机输入框 16px 临时样式；现在由共享外壳统一负责。

## 有意保留的兼容层

- 各静态页面的业务 CSS 和业务 JavaScript：仍负责各自内容，统一外壳只负责布局和公共交互。
- `static-font-scale.js`：静态页面不能使用 React Provider，必须在首屏前独立恢复字号；它和 Next 字号组件共用同一个存储键，但不是重复运行入口。
- `layout.jsx` 的首屏字号恢复：用于避免 Next 水合前先闪出 100% 字号。
- 旧学习状态迁移和 IndexedDB 兼容读取：保护已有进度，不能当作无用旧代码删除。
- 拼写训练专用快捷键：训练输入框有独立提交语义，不能直接套用普通刷词快捷键。

## 固定行为

- 主刷词关系区保留：变形、词族、同义替换、短语搭配。
- 没有资料的关系卡不占空位。
- 不恢复静态主刷词页的“常见搭配”独立卡。
- 阅读生词本右侧生词列表继续保留为唯一允许的长列表滚动区。
- 正式词库、稳定 ID、IndexedDB、SRS 和学习状态不因界面迁移而改写。

## 自动防回归

- 冷缓存主词库必须在 12 秒内离开“正在准备学习内容”，且同一浏览器后续返回首页不能再次下载完整词库。
- 动态学习页与全部独立静态学习页都要逐一验证 80%、85%……160% 共 17 档。
- 每一档同时验证 1366×768 桌面和 390×844 手机：字号必须真实变化，页面不得产生横向滚动条。
- CI 继续通过 `npm run test:e2e` 自动执行这些检查。

## 回退

如果第三阶段出现回归，只回退本说明涉及的导出模板、静态统一外壳和两条新增 E2E；不要回退正式词库或浏览器学习数据。旧的字符串补丁不应重新启用，问题应在对应唯一来源中修复。
